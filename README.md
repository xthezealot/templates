## Download

```sh
git clone --depth=1 --branch=go-web https://github.com/xthezealot/templates.git && rm -r .git && git init
```

## Usage

```sh
# Run the server in live-reload mode
make dev

# Format all the code
make fmt

# Build the final Docker image
make build
```
